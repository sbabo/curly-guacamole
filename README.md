# curly-guacamole

[![React](https://img.shields.io/badge/React-supported-61DAFB.svg)](https://react.dev/)

Pour l test de l'archi et du concept, nous avons choisi de développer un POC d'un outil de Gestion Electronique de Documents (GED) intelligent, conçu pour les entreprises qui souhaitent une solution on premise ou cloud. Cet outil vise à stocker, organiser et partager des documents de manière efficace et sécurisée, tout en intégrant une intelligence artificielle locale pour automatiser la saisie administrative et garantir la sécurité des données.
